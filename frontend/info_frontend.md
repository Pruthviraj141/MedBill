# Frontend Service

This directory contains the frontend portion of the Cafe POS application.

## Tech Stack
- **Framework**: React via Vite
- **Mobile runtime**: Capacitor for Android integration
- **Styling**: Tailwind CSS & Base UI / Shadcn components
- **State Management**: Zustand
- **Database**: Local SQLite syncing (@capacitor-community/sqlite & sql.js)
- **Language**: TypeScript

## Key Commands
- `npm run dev`: Start the Vite development server
- `npm run build`: Typecheck and build for production
- `npm run test:sqlite`: Run SQLite tests locally
